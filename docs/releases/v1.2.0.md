# Context Crystal v1.2.0 — Twinning

Context Crystal `v1.2.0` ("Twinning") expands Context Crystal from isolated session crystals into an interconnected, multi-dimensional context lattice. This milestone introduces **Cross-Crystal Connections & Lattice Bonds**, **Cold Storage Purge & Deletion Symmetry**, the **Golden Triad Agent Onboarding & Skill Auto-Distribution Engine**, and modernized platform runtimes across all target architectures.

In crystallography, *twinning* occurs when two or more distinct crystal individuals intergrow sharing symmetrical lattice points and structural boundaries. In `v1.2.0`, this natural phenomenon inspires both the inter-crystal topological lattice—allowing autonomous agents and developers to link causal streams across separate workspace endeavors—and the resonant unity of the **Golden Triad** (Runtime Binary, MCP Server, and Agent Skill) operating in seamless alignment.

---

## 🚀 What's New & Improved

### 🕸️ Cross-Crystal Connections & Lattice Bonds (`ccrystal connect`, `disconnect`, `connections`)

- **Topological Inter-Crystal Bonds:** Connect distinct session crystals with typed, directed semantic bonds:
  - `supersedes`: Declares that a new crystal replaces or obsoletes a prior crystal.
  - `depends_on`: Models prerequisite dependencies between tasks or architectural milestones.
  - `relates_to`: Establishes symmetrical or bidirectional topical associations.
  - `derives_from`: Tracks provenance, lineage, or exploratory forks across endeavors.
- **Topological Cycle Prevention:** Graph algorithms proactively detect and reject circular dependency loops before bonds are committed to disk.
- **Bounded Lattice Context Beam Projection:** Hydrating a crystal (`ccrystal cast`, `ccrystal hydrate`, or MCP `crystal_hydrate`) automatically projects inbound and outbound lattice bonds, enabling agents to traverse adjacent context without manual lookup.
- **Dedicated MCP Tool & Resource Substrates:** Full integration via `crystal_connect` MCP tool and `ccrystal://{id}/bonds` URI resource streams.
- **Pruning & Deletion Warnings:** Safe deletion commands inspect the lattice and issue actionable warnings when attempting to delete crystals with active inbound or outbound bonds.

### 🧹 Cold Storage Purge, Retention Triage & Deletion Symmetry (`ccrystal prune`)

- **Unified Prune Engine:** Streamlined pruning across active and archived storage via `ccrystal prune` and MCP `crystal_prune` (with backward-compatible `crystal_delete` aliasing).
- **Targeted Cold Storage Purging:** Purge stale or legacy crystals from cold storage (`.ccrystals/archive/`) using `--archived` without touching active workspace crystals:

  ```bash
  ccrystal prune --archived --older-than 30d
  ```

- **Symmetric Companion Cleanup:** Purging permanently unlinks associated artifact files, transcripts, and metadata across both active storage and cold archive directories, preventing orphaned disk debris.
- **Dry-Run & Retention Triage:** Preview deletions safely with `--dry-run` or inspect storage candidates with retention aging filters.

### 🏆 Golden Triad Onboarding & Agent Skill Auto-Distribution (`ccrystal agent`)

- **The Golden Triad Architecture:** Standardizes the three fundamental pillars of agentic AI integration:
  1. **Runtime Binary:** The compiled native or JVM executable (`ccrystal`) available on `$PATH`.
  2. **MCP Server:** Live Model Context Protocol interface configured in client manifests (`agy`, `claude_desktop`, `cursor`, `cline`, `windsurf`, etc.).
  3. **Agent Skill:** Autonomous operational instructions and reflex patterns (`SKILL.md`) installed in agent discovery directories.
- **Golden Triad Diagnostic Matrix (`ccrystal agent doctor`):** Instant verification of all three pillars across registered agent platforms, rendering comprehensive status checks in ~4ms:
  - Platform binary discovery
  - MCP configuration validity
  - Agent skill presence and version freshness (`[OK] Equipped`, `[OUTDATED]`, or `[MISSING]`)
- **Automated Skill Auto-Distribution (`ccrystal agent install`):**
  - **Embedded Canonical Template:** Compiles the canonical `SKILL.md` directly into the binary at build time with zero runtime filesystem dependencies.
  - **Single-Command Setup:** Equips supported agent platforms with both MCP server registration and operational skill instructions in one step:

    ```bash
    ccrystal agent install --target antigravity
    ```

  - **Flexible Linking Modes:** Supports copy-by-default (isolated and safe), `--symlink-skill` (for zero-maintenance auto-updating), and `--workspace-skill` (for repository-local agent instructions).
  - **Version Drift Detection:** Detects when an installed skill file has drifted behind an upgraded binary (`SkillStatus.Outdated`), providing immediate remedial hints.

### ⚡ Standardized Modern Platform Runtimes & Dependency Hardening

- **Universal Temporal Foundation:** Standardized on `java.time` / `scala-java-time` across Native, JVM, and JS targets, replacing custom parsing with standard ISO-8601 formatting.
- **Streamlined Storage IO:** Upgraded filesystem primitives to `os-lib 0.11.8` for consistent, cross-platform path manipulation and directory traversal.
- **Refreshed Dependencies:** Updated cross-platform libraries across Native, JVM, and JS compilation targets.

## 📦 Installation Options

- **Coursier (Universal Zero-Install across Windows, macOS, Linux, BSD):**

  ```bash
  # Instant launch via official Coursier contrib channel:
  cs launch --contrib ccrystal

  # Or install globally to your PATH:
  cs install --contrib ccrystal
  ```

  *(Also available directly via immutable Maven Central coordinates: `cs launch io.github.oswaldo:ccrystal-cli_3:latest.release -- --help`)*

- **Universal POSIX Installer (Native Linux / macOS):**

  ```bash
  curl -fsSL https://raw.githubusercontent.com/oswaldo/context-crystal/main/install.sh | sh
  ```

- **Homebrew (macOS / Linux):**

  ```bash
  brew install oswaldo/context-crystal/ccrystal
  ```

- **Prebuilt Standalone Binaries:**
  Optimized native executables compiled with Thin LTO are attached to the GitHub release for `linux-x86_64`, `linux-aarch64`, `macos-aarch64`, and `macos-x86_64`, along with cryptographic `SHA256SUMS`.
