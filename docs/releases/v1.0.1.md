# Context Crystal v1.0.1

Context Crystal `v1.0.1` brings instant on-demand execution on the JVM via Maven Central, eliminates transient read glitches during rapid agent sessions, and adds zero-configuration installation manifests for AI assistant registries.

## 🚀 What's New & Improved

- **Instant JVM Execution via Coursier & Maven Central:**
  - `ccrystal` CLI and `ccrystal-core` library are now published directly to Maven Central (`io.github.oswaldo:ccrystal-cli_3`).
  - You can now launch Context Crystal instantly on any machine with Java installed (including native Windows, macOS, Linux, and BSD), without compiling or modifying your `PATH`:

    ```bash
    cs launch io.github.oswaldo:ccrystal-cli_3:latest.release -- --help
    ```

  - *(Upstream inclusion for `cs launch --contrib ccrystal` is currently in review via [coursier/apps#339](https://github.com/coursier/apps/pull/339)).*
  - Scala and JVM tooling can now directly depend on `ccrystal-core_3` as an immutable context-persistence engine.

- **Storage Reliability & Concurrency Hardening:**
  - Resolved intermittent JSON parsing and empty file errors when autonomous agents or subshells perform rapid-fire DAG mutations in quick succession. The filesystem store now transparently retries transient read races with exponential backoff before surfacing errors.

- **Ecosystem Manifests & 1-Click Agent Setup:**
  - Added native configuration manifests for **Smithery** and **Glama**, streamlining integration into MCP-compatible coding environments (Claude Desktop, Cursor, Roo Code, Antigravity, etc.).
  - Added native Coursier channel metadata for global package management.

---

## 📦 Installation Options

- **Coursier (Zero-install on any JVM / Universal OS):**

  ```bash
  cs launch io.github.oswaldo:ccrystal-cli_3:latest.release -- --help
  ```

- **Universal POSIX Installer (Native Linux / macOS):**

  ```bash
  curl -fsSL https://raw.githubusercontent.com/oswaldo/context-crystal/main/install.sh | sh
  ```

- **Homebrew (macOS / Linux):**

  ```bash
  brew install oswaldo/context-crystal/ccrystal
  ```

- **Prebuilt Standalone Binaries:**
  Optimized native executables with Thin LTO are available in the release assets below for `linux-x86_64`, `linux-aarch64`, `macos-aarch64`, and `macos-x86_64`.
