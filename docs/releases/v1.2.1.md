# Context Crystal v1.2.1 — Ergonomics & Quality Guards

Context Crystal `v1.2.1` is a developer ergonomics and quality assurance release delivering instant binary version inspection, repository-managed pre-commit and pre-push quality hooks, and zero push-fail CI assurance.

---

## 🚀 What's New & Improved

### 🏷️ CLI Version Flag & BuildInfo Integration (`ccrystal --version`, `-v`)

- **Instant Version Inspection:** Query the installed Context Crystal binary version with zero reflection or overhead:

  ```bash
  ccrystal --version
  # or
  ccrystal -v
  ```

- **Detailed Build Metadata:** Inspect compiler and build provenance using the `--verbose` flag:

  ```bash
  ccrystal --version --verbose
  ```

  Surfaces:
  - Canonical binary name (`ccrystal`) and semantic version string
  - Scala compiler target version (`3.9.0`)
  - SBT toolchain version (`1.13.0`)
  - Exact Git commit SHA hash

### 🛡️ Automated Quality Guards & Git Hooks (`.githooks/`, `scripts/setup-hooks.sh`)

- **Repo-Managed Hook Architecture:** Automated quality hooks live directly under `.githooks/` in Git version control, eliminating setup drift across contributor machines and autonomous AI agent harnesses.
- **`pre-commit` Guard:** Automatically verifies `sbt scalafmtCheckAll` whenever staged `.scala` files are detected, preventing unformatted commits from entering Git history.
- **`pre-push` Guard:** Executes complete quality battery (`sbt "scalafmtCheckAll; scalafixAll --check"` and `sbt test`) prior to pushing to remote forges, guaranteeing zero push-fail CI cycles.
- **Single-Command Activation:** Activate hooks across any local clone using:

  ```bash
  ./scripts/setup-hooks.sh
  ```

- **Emergency Override:** Supports `HOOK_BYPASS=1` or standard `git push --no-verify` when emergency overrides are required.

### 🧪 Cross-Platform Verification & Packaging Hardening

- **Full Multi-Platform Test Pass:** All 141 unit and integration test suites verified passing cleanly across Native, JVM, and JS targets.
- **ReleaseFast Thin LTO Native Packaging:** Hardened release packaging with stripped binary symbols and consolidated `SHA256SUMS` manifests.
