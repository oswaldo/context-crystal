# Context Crystal v1.1.0 — Pleochroism

Context Crystal `v1.1.0` ("Pleochroism") introduces multi-dimensional cave search, temporal querying, comprehensive workspace storage metrics, and quantitative prompt token savings estimation across both the CLI and native Model Context Protocol (MCP) server interfaces.

Like the optical phenomenon of *pleochroism*—where a crystal reveals differing hues and facets depending on the angle of observation—this milestone equips autonomous agents and developers to observe, filter, and quantify workspace context from multiple analytical dimensions, with zero external tracking and 100% local sovereignty.

---

## 🚀 What's New & Improved

### 🔍 Multi-Dimensional Cave Search & Temporal Querying (`ccrystal search` & `crystal_search`)

- **Consolidated Query Engine:** Replaced the legacy `ccrystal list` subcommand with a unified, high-performance search engine across both CLI (`ccrystal search`) and MCP (`crystal_search`).
- **Temporal Querying & Calendar Math:** Pure zero-dependency Gregorian calendar math enabling intuitive date range filtering (`--today`, `--yesterday`, `--since YYYY-MM-DD`, `--until YYYY-MM-DD`).
- **Deep Multi-Facet Filtering:** Filter crystals across metadata, DAG content, and companion stores:
  - Text query across goals, node summaries, lessons, and artifacts (`-q / --query`)
  - Goal lifecycle status (`--status in_progress|concluded_success|concluded_abandoned`)
  - Deterministic aging condition (`--aging active|solid|stale`)
  - Workspace file path touchpoint (`--touching-path <path>`)
  - Author attribution (`--author <entity-id>`)
  - Structural criteria: active leases (`--has-active-leases`), open tasks (`--has-open-tasks`), recorded lessons (`--has-lessons`), and cold storage inclusion (`--archived`).
- **Pagination & Sorting:** Full support for deterministic offset/limit pagination (`--limit`, `--offset`) and multi-field sorting (`--sort-by date|name|status|nodes|tasks`, `--order asc|desc`).

### 📊 Cave Statistics, Storage Metrics & Token Savings (`ccrystal stats` & `crystal_stats`)

- **Quantitative Observability Dashboard:** New CLI subcommand `ccrystal stats` and MCP tool `crystal_stats` provide immediate workspace health and efficiency insights:
  - **Temporal Genesis:** Identifies the oldest crystal (initial genesis) and newest crystal (latest beam), calculating total cave lifespan in days.
  - **Structural Inventory:** Global counts of crystals (active vs archived), DAG transition nodes, tasks (completed vs open), active resource leases, lessons learned, and registered entities.
  - **Disk Storage Footprint:** Exact byte counts across active cave (`.ccrystals/`) and cold storage (`.ccrystals/archive/`), with average footprint per crystal.
  - **Prompt Token Savings:** Deterministic token estimator comparing raw DAG transcript re-ingestion against selective hydration (`ccrystal cast/hydrate`) and sub-DAG melting (`ccrystal melt`), calculating quantitative context window savings (typically 50%–70%+ reduction).
  - **Health Distribution:** Aggregated breakdown of crystals by goal status and aging condition.
- **Machine-Readable & Detailed Modes:** Pass `--json` for automated agent consumption or `--detailed` for per-crystal metric breakdowns. Filter arguments from `search` are fully supported to scope stats to specific subsets.

### 🛡️ Batch Execution & Shell Robustness

- **Preserved Quoted Semicolons:** The atomic batch parser now preserves quoted semicolons inside shell strings and commands, preventing premature statement splitting.
- **Pre-Validation:** Enhanced pre-validation across batch operations to catch syntax anomalies before DAG mutations begin.

## 📦 Installation Options

- **Coursier (Universal Zero-Install across Windows, macOS, Linux, BSD):**

  ```bash
  # Instant launch via official Coursier contrib channel:
  cs launch --contrib ccrystal

  # Or install globally to your PATH:
  cs install --contrib ccrystal
  ```

  *(Also available directly via immutable Maven Central coordinates: `cs launch io.github.oswaldo:ccrystal-cli_3:latest.release -- --help`)*

- **Universal POSIX Installer (Native Linux / macOS):**

  ```bash
  curl -fsSL https://raw.githubusercontent.com/oswaldo/context-crystal/main/install.sh | sh
  ```

- **Homebrew (macOS / Linux):**

  ```bash
  brew install oswaldo/context-crystal/ccrystal
  ```

- **Prebuilt Standalone Binaries:**
  Optimized native executables compiled with Thin LTO are attached to the GitHub release for `linux-x86_64`, `linux-aarch64`, `macos-aarch64`, and `macos-x86_64`, along with cryptographic `SHA256SUMS`.
